# Documentación de desarrollo

- `status.md`: estado vigente, límites, última evidencia y siguiente paso; objetivo máximo 350 palabras. No acumules tablas históricas.
- `history.md`: evidencias anteriores. Añade registros fechados; no reescribas comprobaciones pasadas como recién ejecutadas. No es lectura inicial.
- `development.md`: mapa/recetas de mantenimiento de este repositorio. Rutas/comandos existentes; no planificación de funcionalidades de IA.
- Actualiza solo la guía de dominio afectada. Producto/arquitectura/roadmap contienen decisiones/planes, no disponibilidad comprobada ni autorización de otra entrega.
- Español, enlaces relativos válidos, pruebas simuladas/reales diferenciadas. Sin secretos, dumps, logs completos o reglas duplicadas.

Solo documentación: enlaces, coherencia y whitespace; sin levantar servicios, inferencias o toda la suite. Raíz breve; reglas específicas junto al código.
